How Codes Work

• Buyers enter the code during checkout on the event page

• Percent codes apply a % off the total, fixed codes deduct a flat amount

• Codes are scoped to a single event — create separate codes per event

• Platform commission (3%) is applied on the discounted price

• Codes are auto-uppercase alphanumeric only
