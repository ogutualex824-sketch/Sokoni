🔌 P58E Bluetooth Pairing Guide
1
Power on the P58E
Hold the power button until the LED turns blue and you hear a beep. The printer will print a self-test page.
2
Enter pairing mode
The blue LED should blink. If it's solid blue, press and hold the Feed button for 3 seconds to enter pairing mode.
3
Click "Pair P58E Printer" below
A browser Bluetooth picker will open. Select your printer from the list (look for a name starting with P58 or the device name printed on the self-test page).
4
Click "Pair" in the browser dialog
No PIN required. The browser remembers this printer. Future page loads will auto-connect without any dialog.
✓
Print a test receipt
Go to the Hardware Tests tab and click "Print Test Receipt" to verify everything works. The receipt will include printer info, sample products, a barcode, and a QR code.

❓ Troubleshooting
Printer not showing in the picker
• Make sure the printer is powered on and the LED is blinking blue
• Press and hold the Feed button for 3 seconds to enter pairing mode
• Check that Bluetooth is enabled on this device
• Try moving closer — BLE range is ~10m in open air
• If the printer has already been paired to another app, remove it from the OS Bluetooth settings first
Connected but nothing prints
• Check the paper roll is loaded correctly and not jammed
• Go to Hardware Tests → Print Test Receipt
• Try disconnecting and reconnecting
• Verify the paper width setting matches the loaded paper (58mm for P58E)
• The BLE write chunk size is 128 bytes with 40ms delay — no action needed, this is applied automatically
Printer disconnects frequently
• Keep the printer within 5m of the device
• Check the printer battery level (low battery causes disconnects)
• Make sure no other app is connected to the same printer
• Auto-reconnect will restore the connection within 1–30 seconds automatically
Auto-connect not working after page reload
• Auto-connect requires Chrome 85+ and the printer to be powered on
• This uses navigator.bluetooth.getDevices() — no user gesture required
• If it still doesn't work, go to Chrome Settings → Site Settings → Bluetooth → check SOKONI has permission
• Manually click "Reconnect" if auto-connect fails
Cash drawer not opening
• The cash drawer must be connected to the printer's RJ11/RJ12 port
• The ESC/POS drawer kick command (ESC p) is sent to the printer, not the drawer directly
• Some P58E models may not support the drawer kick — check the specification sheet
• Try "Test Cash Drawer" in Hardware Tests to verify
