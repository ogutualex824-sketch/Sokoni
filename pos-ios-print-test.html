Why no Bluetooth on iPhone?
Apple has not implemented the Web Bluetooth API in WebKit (Safari, or any browser on iOS — including Chrome, Firefox, and Edge, which all use WebKit on iOS due to App Store rules). This is a platform-level decision by Apple, not a SOKONI limitation. Bluetooth printing requires a native iOS app.

AirPrint Test Manual — verify iOS print dialog appears
MANUAL

Tap Print / AirPrint below. A receipt opens and the iOS print dialog appears. From that dialog you can:

  • Print to any AirPrint-certified network printer on the same Wi-Fi
  • Save as PDF — tap the share icon in the bottom-left of the print dialog, then choose "Save to Files" or "AirDrop"
Note: The P58E Bluetooth thermal printer does not support AirPrint — it is a BLE-only device. AirPrint works with HP, Canon, Epson, and other certified network printers. If no AirPrint printer is available, confirm the dialog appeared — that is sufficient to PASS this test. PDF generation via the print dialog is always available.

Save as PDF opens the receipt in a new tab. On iOS, use the Share button → Save to Files to save a PDF.
