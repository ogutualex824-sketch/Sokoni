HOW TO COMPLETE THE CHROME PICKER
1. Click Pair Printer below — a Chrome dialog will open.
2. Find P58E in the list. If it shows "Paired", that is the OS status — you still need to select it.
3. Click on P58E so the row is highlighted/selected.
4. Click the "Pair" button at the bottom right of the Chrome dialog.
5. Wait — do not close the dialog while it connects.
After this first selection, this page uses getDevices() on every reload — no picker needed again.
If P58E does not appear in the list, use Show All Devices to see everything nearby.
Browser security model: requestDevice() always requires a user gesture and opens a picker. Once you select the device, getDevices() reconnects silently on every refresh. Closing the picker is a browser permission event — it is not a printer error.
