Quick Start

The SOKONI API lets you read and write orders, products, inventory, payments, and more from any external system. Every request is authenticated with an API key issued from this portal.

Authentication

Pass your key in every request header:

X-Sokoni-Key: sk_live_your_key_here
Content-Type: application/json

Keys prefixed sk_test_ target a sandbox environment — no live data is affected.

Base URL

https://api.mysokoni.co.ke/v1

Common Requests

# List orders
curl https://api.mysokoni.co.ke/v1/orders \
  -H "X-Sokoni-Key: sk_live_..."

# Get a single product
curl https://api.mysokoni.co.ke/v1/products/{productId} \
  -H "X-Sokoni-Key: sk_live_..."

# Update inventory quantity
curl -X PATCH https://api.mysokoni.co.ke/v1/inventory/{itemId} \
  -H "X-Sokoni-Key: sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"quantity": 50}'

Webhook Payload

{
  "event": "order.created",
  "timestamp": "2026-07-07T10:30:00Z",
  "data": {
    "orderId": "ord_abc123",
    "total": 1500,
    "currency": "KES",
    "status": "pending"
  },
  "signature": "sha256=a3f9c..."
}

Verify HMAC-SHA256 signatures to confirm payloads are from SOKONI:

const computed = crypto.createHmac('sha256', WEBHOOK_SECRET)
  .update(rawBody).digest('hex');
if (`sha256=${computed}` !== req.headers['x-sokoni-signature'])
  return res.status(401).end('Rejected');

Firebase SDK

import { getFunctions, httpsCallable } from 'firebase/functions';

const fn = getFunctions(initializeApp(sokoniConfig), 'us-central1');
const result = await httpsCallable(fn, 'getProducts')({ limit: 20 });
