## Proof obligation, per group

Removal is proven by **differential evaluation**, not by inspection: the same request
set is evaluated against the served source and against the candidate, and every verdict
must match. A candidate that changes a single ALLOW/DENY is rejected outright.

The sabotage control: a deliberately altered candidate — one granting rule weakened —
must make the harness FAIL. A harness that passes everything proves nothing.
