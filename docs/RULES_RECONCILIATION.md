1. Start from `firestore.rules.live` (the known-good baseline).
2. Apply **one category** of changes, scoped to its own `match` block.
3. Run the emulator suites against the candidate:
   `RULES_FILE=<candidate> firebase emulators:exec --only firestore --project <test> "node scripts/test-*-rules.js"`
4. Diff the candidate against `firestore.rules.live` and confirm **only** the intended lines changed.
